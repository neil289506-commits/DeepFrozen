# DeepFrozen

Brings the **Ice Caves** content from Minecraft 26.4 to older versions: 26.1, 26.1.1, 26.1.2, 26.2 and 26.3. Fabric only.

> **Requires [Fabric API](https://modrinth.com/mod/fabric-api).** Java 25 and Fabric Loader 0.19.5 or newer.

## What's included

**Blocks**
- Packed Ice Bricks, with slab, stairs, wall and Chiseled Packed Ice
- Snow Bricks, with slab, stairs and wall
- Calcite set: Calcite Pillar, Polished Calcite, Polished Calcite Bricks, each with slab, stairs and wall
- Brittle Ice, Ice Crystal and Icicle (grows under packed ice, falls when it would melt)

**Mobs and items**
- Frostbite (a frozen zombie variant that throws ice balls) and its spawn egg
- Ice Ball
- Freezing effect, plus Potion of Freezing, Splash, Lingering and Tipped Arrow variants
- Flurry music disc

**World generation**
- Ice caves and ice crevasses in frozen biomes

## Supported versions

| Minecraft | Status |
|---|---|
| 26.2 | Reference version |
| 26.1, 26.1.1, 26.1.2 | Ported, in testing |
| 26.3 | Ported, in testing |

This is an early release. Only 26.2 has been used as the base; the other versions are fresh ports, so please report anything that breaks.

## Notes

- Back up your world before adding the mod to an existing one.
- The mod adds new blocks and a mob, so removing it later will delete them.

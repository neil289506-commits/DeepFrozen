安裝教學

三個步驟,放進 mods 資料夾就能玩。

安裝步驟

安裝 Fabric Loader

安裝 Fabric Loader 0.19.5 以上(Java 25)。

下載 Fabric API

前往 Modrinth 下載對應版本的 Fabric API。

下載 DeepFrozen

從 Modrinth 或下方的 GitHub Release 下載對應版本,放進 mods 資料夾。
